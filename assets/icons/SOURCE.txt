icons_classic/ = spr_icons（经典主题的 UI 字形），icons_light/ = spr_icons_f（Fluent 浅色主题的深字），icons_d/ = spr_icons_d（Fluent 深色 / 选中态的浅字），icons_accent/ = spr_icons_col（叠在字形上的强调色层）；都是 64 帧 25x25（3.12 在铜块一族上多了 4 帧，后面的字形整体后移 4），帧号就是原版 `enum icons` 的下标（scripts/icons_init/icons_init.gml）。目录名是导出后改的，所以和精灵名不完全一致。
iconbar/ 只用到 00-02（原版 draw_sprite(spr_iconbar, 0/1/2) 的左端帽、可拉伸中段、右端帽），每帧 2x30；03-08 是原版工程里存在但从未被引用的帧，一并导出以保持序号一致。
back/ = spr_back，4 帧，序号 = fdark + 2 * 按下（draw_window_preferences.gml:58 的首选项返回按钮），每帧 16x16，原版画在 x1+14, y1+42。
button_arrow/ = spr_button_arrow，15 帧，序号 = m + 3 * theme + 3 * (fdark && theme = 3)，其中 m = 0 未悬停 / 1 悬停 / 2 悬停且按下（draw_abutton.gml:6-9），每帧 17x18。
window/ 不是精灵图，是首选项「界面 → 图标 → 旧图标」换的两个窗口图标（control_create.gml:59-60、control_draw.gml:27-31），两者都是 256x256 8bit RGBA：
  new.png = 程序自带的立方体音符盒。取自装机版 Minecraft Note Block Studio.exe 内嵌的 RT_ICON #2（256x256 PNG，33866 字节），与仓库 options/windows/icons/icon.ico 里那一条逐字节相同，两边对得上。
  old.png = 圆角方块的老图标。取自装机版 Data\icon.ico（256x256 PNG，52478 字节）。仓库 datafiles/Data/icon.ico 是同一条目的旧版（37236 字节，格纹更浅），装机版 3.12 已经换深了，这里以装机版为准。
yesno/ = spr_yesno，3 帧 32x32，原点 (16,16)（精灵画在中心）：0 红叉、1 绿勾、2 橙勾 + 警告三角。原版兼容性窗口每条检查前面的图标，draw_window_minecraft.gml 里 `draw_sprite(spr_yesno, 状态, x1 + 25, yy + 8)`。
yesno_f/ = spr_yesno_f，9 帧 32x32，原点 (16,16)：0-2 浅色底图、3-5 深色（fdark）底图、6-8 白色蒙版。Fluent 主题先画 `状态 + 3 * fdark`，再叠 `状态 + 6` 并染 accent[6 - 2 * !fdark]，所以勾/叉/三角本身是强调色，底图只有深灰描边。
../extranotes.zip = 装机版 D:\software\NBS\Data\extranotes.zip 原样拷贝（462095 字节，md5 152915fa5ddf5d53610b2b6f4e686e6e），不是我们生成的。原版 datapack_getextranotes.gml 就是 `file_copy(data_directory + "extranotes.zip", fn)`，nbs-io 用 include_bytes! 内嵌同一份字节。
block_color/ = spr_block_color、block_shape/ = spr_block_shape、block_color_shape/ = spr_block_color_shape，都是 38 帧 32x32、原点左上；网格里的音符盒按 (use_colors, use_shapes) 从这三套里选一套，内置乐器 0..19 直接用帧号，自定义乐器用 (序号 - 20) % 18 + 20 循环取 20..37。block/ = spr_block 只有 1 帧（两套开关都关时用它，原版传的帧号 1 越界，画的就是这一帧）。block_sel/ = spr_block_sel，选中叠层。
instrumenticons/ = spr_instrumenticons，21 帧 16x16：0..19 是 20 个内置乐器的方块贴图，20 是自定义乐器的通用底图（draw_icon_customins 会把它染成 make_color_hsv((ins * 16) % 256, 192, 255) 再叠两位 MC 数字）。
wall/ = spr_wall，2 帧 16x1（拉伸使用）：黑色渐变（帧 0）和白色渐变（帧 1），alpha 0,18,41,64,100,141,192,255,255,0…，不透明段在第 7-8 像素，精灵 xorigin = 1。消音器导引带（draw_sound_stopper_guide.gml）：画在 `_x - 1 - xoffset` 处并按编辑区左右边界裁源，纵向拉到 32 * (结束层 - 起始层 + 1)；起止层分别取 `abs(song_pit)` 和 `panning_velocity_to_short(pan, vel)`（1 基层号），起始层越过结束层时直接 return（画不出任何东西）。
tempo_changer_label/ = spr_tempo_changer_label、tempo_changer_label_mc/ = spr_tempo_changer_label_mc，各 2 帧 7x7 / 11x11：0 是 Tempo Changer、1 是 Sound Stopper 的角标（draw_icon_customins.gml）。mc 版画在方块中央（+3,+3 染色 2 / +2,+2 白色），小版画在 16x16 图标右下（+12,+12 染色 2 / +11,+11 白色）；非事件自定义乐器画两位 MC 数字，由 draw_icon_customins 按乐器名分流。
interface1/ = spr_interface1，40 帧 2x2 = 每主题 8 帧 x 5 主题：每主题 0/2/4/6 是四角、1/5 纵向拉伸、3/7 横向拉伸（draw_area.gml），帧基值 = 8 * theme + 8 * (theme = 3 && fdark)。标尺 BPM 盒的边框用它画（control_draw.gml:1163）。
notechart/ = spr_notechart 的 4 个面板帧（原帧号 0/3/6/9 = 3 * theme，文件名沿用原帧号），320x320、原点 (0,0)；notechart_pointer/ = 同一精灵的 8 个指针帧（原帧号 1/2 + 3 * theme），内容只在左上 17x15，导出时裁成 20x20（内容贴左上角，画出的像素不变）。整条 12 帧合成 3840px 会超出 egui 纹理边长上限 2048，所以拆成两条；指针帧号 = 2 * 主题序号 + 右缘。悬停琴键时面板画在 (median(0, x1-32, rw-320), yy-320+1)，指针画在 (x1 - 16*(x1 > rw-250), yy)（draw_notechart.gml）。
gclef/ = spr_Gclef，2 帧 30x82、原点 (18,50)，第 1 帧原版从未引用；fclef/ = spr_Fclef，1 帧 40x44、原点 (8,13)。谱号画在五线谱面板内固定位置（G 谱号 xx+58, yy-250+48；F 谱号 xx+48, yy-250+112）。
note_sharp/ = spr_note_sharp、note_flat/ = spr_note_flat，各 4 帧 49x150、原点 (30,74)：帧 = accidental + 2 * (key > 22)，0/1 在下段音区、2/3 在上段音区；升降随 keynames_flat 选套。画在 (xx+152, yy-250-8*(key-33))，加线从 xx+122 到 xx+180。
logo/ = spr_logo，3 帧 330x330、原点 (28,32)：0 默认、1 旧图标（首选项选了自定义窗口图标）、2 旧图标 + fdark（帧 = window_icon + (window_icon && fdark)，control_create.gml:59）。欢迎窗按 0.5 缩放画在 (x1+64, y1+50)，左上角落在 (x1+50, y1+34)（draw_window_greeting.gml:34）。
donate/ = spr_donate，4 帧 150x120、原点 (0,0)：0/1 是右上角 16x16 的关闭叉（常/悬停），2/3 是横幅文案（英文/中文）。欢迎窗贴在窗口右缘 (x1+700, y1+110)，先画叉帧再叠文案帧；点叉提示后 donate_banner_time = 下个月的今天写回 [warnings]，点横幅其余部分打开捐赠页（draw_window_greeting.gml:10-36）。
frame2/ = spr_frame2 的 Aqua 三帧（原帧号 0/1/2 = 按下态 + 3*0），frame2_retro/dark/fluent/fluent_d = 同一精灵按主题方言拆出的 3/6/9/12 帧组（fluent_d = 主题 3 且 fdark），各 224x32、原点 (0,0)；frame5/… = spr_frame5 同样拆五条，各 320x16，是欢迎窗动作按钮和最近歌曲行的底图（draw_window_greeting.gml）。整条 15 帧 224 一乘就超 egui 纹理边长 2048，所以按方言拆五条。
bigicons/ = spr_bigicons，8 帧 32x32：0 创建歌曲、1 打开歌曲、2 从 MIDI 生成、6 浏览社区歌曲（draw_window_greeting.gml）；bigicons_f/ = spr_bigicons_f（Fluent 浅）、bigicons_d/ = spr_bigicons_d（Fluent 深），主题 3 时按 fdark 二选一，其余主题用 bigicons。
songtab/ = spr_songtab，30 帧 4x31：每主题 10 帧，0/1/2 常态、3/4/5 未选中悬停、6/7/8 选中；9 是横向拉伸底图。draw_song_tab.gml 用左/中/右三帧拼标签，draw_song_tabs.gml 用 9+10*theme 铺底。
closetab/ = spr_closetab，4 帧 9x9：0/1 经典主题常态/悬停，2/3 Fluent 未改/已改；Fluent 浅色用黑、深色用白。
newtab/ = spr_newtab，1 帧 15x15：Fluent 标签条右侧加号；非 Fluent 的加号由 spr_songtab 的 0/1/2 三帧拼出。
